# SBM Taxonomy Prototype (Interactive)

Interactive prototype for taxonomy instantiation with:
- guided navigation across six dimensions;
- category assignment, evidence source, rationale, and secondary notes;
- PDF export of the final classification report.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- jsPDF + jspdf-autotable

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
